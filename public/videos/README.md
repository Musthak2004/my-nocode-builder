# Hero Background Video

Place your hero background video at `public/videos/hero-bg.mp4`.

**Recommended spec:**
- Format: MP4 (H.264)
- Resolution: 1920×1080 or higher
- Duration: 10-30 seconds (loops)
- File size: Keep under 5MB for performance
- Style: Cinematic, slow-paced, dark-toned

**Free sources:**
- Coverr.co (https://coverr.co)
- Pexels Video (https://www.pexels.com/videos)
- Mixkit (https://mixkit.co)

The video component uses `autoPlay`, `muted`, `loop`, `playsInline` and falls back gracefully (dark gradient background) if the video fails to load.
